## 本地浏览

将本仓库文件放在同一目录，用浏览器打开 `index.html`。头像与封面已内嵌，视频使用相对路径 `./gallery-demo.mp4`。

## 视频版本

- 时长：约 8 分 28 秒。
- 分辨率：1280 × 800；视频编码 H.264，音频 AAC。
- 使用两遍编码与 Fast Start，支持网页按需加载。
- 发布文件大小：21.05 MiB，较原始视频缩小 89.4%。
- 原视频与原始头像保留在本地，不提交到仓库。

## GitHub Pages

发布来源使用 **main 分支根目录**：

1. 打开仓库的 **Settings → Pages**。
2. Source 选择 **Deploy from a branch**。
3. Branch 选择 **main**，目录选择 **/(root)**，保存。
4. 部署完成后从 Pages 设置中的 **Visit site** 访问网页。

页面支持手机与电脑布局，导航支持键盘操作，动效尊重系统的 `prefers-reduced-motion` 设置。375px 宽度的浏览器模拟检查未发现横向溢出；尚未完成真实手机测试。
